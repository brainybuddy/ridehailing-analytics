## FAQ for Proposal Package

**Q: Which document should I send first?**
A: Start with One_Page_Summary.md in an email. If they show interest, follow with Executive Summary. Save full proposal for after initial call.

**Q: Should I send all documents at once?**
A: No. Use a drip approach:
- Email 1: One-pager
- Email 2 (after interest): Executive summary
- Email 3 (after demo): Full proposal

**Q: How do I customize for different African markets?**
A: The Lagos data is the proof-of-concept. Emphasize in proposal:
- "Lagos model scalable to Nairobi, Accra, Cape Town..."
- "Platform expandable for multi-city analytics..."
- "Pan-African vision starts with Lagos validation..."

**Q: What if they want a pilot project first?**
A: Offer 30-day trial:
- Limited dashboard access
- One custom use case (e.g., charging station placement)
- Sample report generation
- Cost: $5K-$10K, applied to full partnership if they proceed

**Q: How do I price for different organizations?**
A: Adjust by organization size and scope:
- Startups/NGOs: Lower end ($25K-$50K)
- Mid-size organizations: Mid-range ($50K-$100K)
- Large organizations/governments: Upper range ($150K-$300K)

**Q: What if they only want the data, not the platform?**
A: Data-only licensing option:
- Raw CSV files: $15K-$25K
- No dashboard, no support
- One-time license for internal use
- (Not recommended - platform is the value-add)
